This repository hosts the official Privacy Policy for the Android educational mobile game **Cash Register Rush** (`com.mouse.cashregister`) developed and published by **Green Mouse**.

---

### Key Privacy Highlights
- **Zero Data Collection:** The game does not collect, transmit, store, sell, or share any personal data, location data, or device identifiers.
- **100% Offline Operation:** All gameplay, graphics, multilingual translations, sounds, and music run entirely offline with zero network requests.
- **Zero Sensitive Permissions:** No access to internet, camera, microphone, contacts, location, or external storage.
- **No Advertisements, Trackers, or IAP:** 100% free of ads, analytics, third-party SDKs, and real-money purchases.
- **Child-Safe & Family-Friendly:** Fully compliant with Google Play Families Policy, COPPA, and GDPR-K.
